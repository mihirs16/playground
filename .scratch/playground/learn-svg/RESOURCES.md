# Resources

High-trust sources for the Rotating SVG course. Prefer these over parametric guesses.

## Primary (canonical)
- **MDN — SVG Basic Shapes tutorial** · https://developer.mozilla.org/en-US/docs/Web/SVG/Tutorial/Basic_shapes
  The reference for rect/circle/line/polyline/polygon. Used in Lesson 1.
- **MDN — SVG element reference** · https://developer.mozilla.org/en-US/docs/Web/SVG/Element
  Every element + attribute, authoritative.
- **MDN — SVG viewBox** · https://developer.mozilla.org/en-US/docs/Web/SVG/Attribute/viewBox
  Coordinate system + scaling. For Lesson 2.
- **MDN — SVG transform** · https://developer.mozilla.org/en-US/docs/Web/SVG/Attribute/transform
  translate / rotate(deg, cx, cy) / scale. For Lesson 3.
- **MDN — requestAnimationFrame** · https://developer.mozilla.org/en-US/docs/Web/API/Window/requestAnimationFrame
  The render-loop primitive. For Lesson 4.
