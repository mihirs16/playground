SVG primitives cheat sheet

The elements and attributes the exploded-axonometric prototype is built from. Coordinates are in viewBox units, origin top-left, y grows downward.

Canvas

<svg viewBox="minX minY width height"> … </svg>
  viewBox   which slice of the grid is shown (units, not px)
  width/height   the pixel size of the box on the page

Shapes

<rect x y width height rx? />      box; rx = corner radius
<circle cx cy r />                 centre + radius
<ellipse cx cy rx ry />            oval
<line x1 y1 x2 y2 />               one segment
<polyline points="x,y x,y …" />    open multi-point path
<polygon  points="x,y x,y …" />    closed shape (auto-joins last→first)

Paint

fill="#rrggbb" | "none"            interior colour
stroke="#rrggbb"                   outline colour
stroke-width="n"                   outline thickness (units)
stroke-dasharray="4 3"             dashed: 4 on, 3 off  → drop-lines, routes
opacity="0..1"                     whole-element transparency
fill-opacity / stroke-opacity      paint each separately

Structure

<g> … </g>                          group; share transforms/styles
<pattern>                          tileable fill (hatching)
<text x y>label</text>             text at a point

Transforms (Lesson 3+)

transform="translate(dx dy)"       move
transform="rotate(deg cx cy)"      rotate deg° about pivot (cx,cy)
transform="scale(s)"               grow/shrink about origin
/* multiple: applied right-to-left */
transform="translate(50 50) rotate(30)"

Building nodes in JS

// SVG needs the XML namespace — createElement won't work:
const NS = "http://www.w3.org/2000/svg";
const el = document.createElementNS(NS, "polygon");
el.setAttribute("points", "0,0 10,0 5,8");
el.setAttribute("fill", "#a4531f");
svg.appendChild(el);
