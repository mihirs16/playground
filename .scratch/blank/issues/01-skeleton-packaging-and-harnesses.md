# 01 — Skeleton: Lit/TS package, packaging shape, and both harnesses

**What to build:** A booting `blank` package in its final publishable shape, with
nothing aesthetic yet — the foundation every later ticket hangs off. It is a Lit +
TypeScript library authored with the `@customElement` decorator, published ESM-only
with an `"exports"` map that has per-component subpaths (`blank/button`, …) plus a
barrel. Importing a component auto-registers its custom element as a side effect, and
those entry files are listed in `package.json` `sideEffects` so bundlers never prune
registration. Lit is declared a `peerDependency`. A Custom Elements Manifest is
generated by the analyzer, committed, and CI-drift-checked. Both verification surfaces
are proven against a single trivial element: the real-browser test seam (Web Test
Runner on a Playwright/Chromium launcher) asserting only through the public
custom-element interface, and the no-build static-HTML demo page opened directly in a
browser with a light/dark toggle.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent
